# BYD Seal 2026 Landing Concept

Prototype nhanh cho concept landing page phong cách Tesla + Apple + BMW:

- Fullscreen hero với dark background
- "Car stage" mô phỏng xe 3D (placeholder) + hover headlight glow
- Scroll storytelling (range, LED, interior)
- Color switch realtime
- Booking/đặt cọc form cơ bản

## Chạy local

Mở trực tiếp `index.html` trong browser.

## Hướng nâng cấp production

- Chuyển sang Next.js + TailwindCSS
- Dùng React Three Fiber + model `.glb` BYD Seal
- GSAP ScrollTrigger cho camera path cinematic
- Tích hợp API đặt lịch lái thử / đặt cọc online
